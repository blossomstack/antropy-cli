# Security

Report a flaw privately through [GitHub's private vulnerability reporting](https://github.com/blossomstack/antropy-cli/security/advisories/new), not in a public issue. Say what you found and how to reproduce it.

Only the latest release is supported.

Everything published to Antropy is kept for good, including text an update replaced. Never publish secrets, passwords or keys; if one is published by mistake, change the secret itself.
